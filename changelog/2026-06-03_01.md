## Why Care?

If you've ever tried to explain a thing that isn't a company without sounding like a company trying not to sound like a company, you'll recognize the problem. The previous /about page leaned on stock org-page tropes — "Our Team", "Our Projects", a CTA to View on GitHub — and the result read like a small consulting firm hedging on whether it was a small consulting firm.

The Lossless Group isn't a consulting firm. It isn't a company. It's an **umbrella brand** — a cooperative of innovators who house their advisory, building, and tinkering under one roof so they can share context, conventions, and craft without giving up their own work. That's a different shape than "company", and the page now reflects it.

The redesign also pulls four new humans onto the team page and quietly anonymizes the client carousel so we can talk publicly about who we work with without naming who we work with.

## What's New?

- **Sharpened anti-company messaging.** "Less of a Company. More of a Cooperative." Three pillars (Friends First, Open by Default, Lossless Not Lossy) replace the old generic-sounding "social club" framing.
- **Curated five-tier project taxonomy** in place of the old four-tile static grid:
  1. **Foundations** — Context Vigilance Kit, Lossless Flavored Markdown, Lossless Agent Skills (the packages that underpin everything)
  2. **Astro Knots** — the platform our client sites are built on
  3. **AI Labs** — MemoPop AI, DDDecks AI, Augment-It
  4. **AI Transformation Advisory** — Emergent Innovation, Essays, Presentations (the thought-leadership tier)
  5. **Everything Else** — single link out to the GitHub org for experiments, forks, and beautifully abandoned projects
- **Four new humans on the team page**: Andrea Capera Patino (backend / devops), Matt Holmes (CEO, Cobuy.io), Katelyn Donnelly (Managing Partner, Avalanche VC), Harjyot Sahni (HealthTech / TBI research).
- **Two new clients in the carousel**: Reach (apprenticeship-degree university) and HUMAIN (emerging longevity / healthspan venture manager). Favicons fetched and saved locally so they render off-line.
- **Anonymized client display.** Swapped `ClientListHorizontalScroller` for the `--stealth` variant that the homepage already uses; pulls `stealth-name` / `stealth-logo` / `stealth-description` from the same `clients.json`. The project grid's per-card `ClientIcon` row also got dropped — that was a second leak of client identity via the public logo.
- **Social row directly under the wordmark**, mirroring the icons in `Header.astro` (YouTube, X, GitHub, LinkedIn, Buy Me a Coffee).
- **First ever `site/changelog/`.** This entry is the seed of it.

## A New Changelog Folder

This is also the first entry in `site/changelog/`. Historically, changelog entries for this codebase have lived in an external managed directory. We're moving — philosophically and structurally — toward **every project owning its own `changelog/`**, with pseudomonorepo parents rolling up their submodules' entries into a unified feed at build time. The rollup mechanism isn't wired yet for this site, but writing the entry where it belongs is the first step. (See the `pseudomonorepos` skill's `content-rollup.md` reference for the eventual mechanism — local-filesystem aggregation for in-tree children, GitHub Content API for out-of-tree ones.)

## How the Taxonomy Maps to Real Work

The five tiers aren't decorative — they map to how the work actually composes:

```
Foundations (packages)
   │
   ├── Astro Knots ──→ client sites at scale
   │
   ├── AI Labs ──→ MemoPop, DDDecks, Augment-It
   │                 (VC Ops / Consulting Ops products)
   │
   ├── AI Transformation Advisory ──→ Essays, Presentations,
   │                                   Emergent Innovation
   │                                   (thought leadership / frameworks)
   │
   └── Everything Else ──→ github.com/lossless-group
                            (experiments, forks, abandoned)
```

The packages aren't a sidebar — they're the *base*. Astro Knots, AI Labs, and the Advisory tier are all consumers of the foundations. The taxonomy reads top-down on the page but, conceptually, the foundations are the floor everything else stands on.

## Under the Hood

A few specific decisions worth flagging for the next person who touches this page:

- **Project data is curated, not pulled from `project-gallery.json` anymore.** The previous version mapped `Object.values(projectGallery.projects)` into a flat grid. That's a fine view for `/projects/`, but on /about it gave equal visual weight to a foundational package and a one-off experiment, which is exactly the wrong story. The new page hand-curates four arrays (`foundations`, `aiLabsChildren`, `advisoryChildren`, and the inline Astro Knots feature) so the hierarchy is editorial, not algorithmic.
- **Anonymization is data-driven, not view-driven.** `clients.json` already had `stealth-name` / `stealth-logo` / `stealth-description` / `stealth-passcode` fields on every entry — the homepage was already consuming them via `ClientListHorizontalScroller--stealth`. We just pointed /about at the same component. New clients (Reach, HUMAIN) include both their public and stealth identities so adding them to either view is now zero-cost.
- **Favicon fetch quirk for Reach.** `https://reach.edu/favicon.ico` actually serves a 1080×1080 PNG (correct bytes, wrong extension). Renamed to `.png` on save. The user later pointed at `https://reach.edu/hubfs/Reach%20University%20Favicon.png` — same file, canonical URL. Saved as `/visuals/appIcon__Reach.png`.
- **GitHub icon CSS bug, caught in review.** The Everything Else CTA's `<svg>` initially rendered at full viewport size because the new tier classes (`.tier`, `.package-card`, `.feature-card`, `.everything-else-cta`, etc.) didn't have CSS yet. Added the full ruleset and constrained the SVG to 20×20. Lesson: always pair HTML scaffolding with at least minimal layout CSS in the same commit, or the next refresh is a giant octocat.
- **Three placeholder links** that may 404 until follow-up: `/projects/gallery/emergent-innovation` (gallery entry exists in JSON but has no `href`), `https://github.com/lossless-group/dddecks-ai` (guessed slug), `https://github.com/lossless-group/lossless-agent-skills` (guessed slug). Flagged in the response to the user; not blocking.
